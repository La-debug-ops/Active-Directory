# Active-Directory Project

## Description
The purpose of the active directory project is set up set up and manage Active Directory through installing virtual box, configuring the DHCP server, and adding Windows 10 to the domain onto a Windows 2019 domain controller server. The essential skills utilized include:

 ✔️Configure networking and IP addressing.
 ✔️ Deploy server roles (AD, DHCP, NAT, RAS).
 ✔️ Implement basic security measures.
 ✔️ Use PowerShell to automate tasks.
 ✔️ Manage users and permissions in a corporate environment.
 ✔️ Troubleshoot network and domain-related issues.
